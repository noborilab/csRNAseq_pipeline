csRNA library alignment statistics
------------------------------------

Tag counts and read origin extracted from HOMER tag directories.

- **TotalReads** — total aligned and filtered reads in the tag directory
- **PtReads** — reads mapping to the plastid chromosome
- **MtReads** — reads mapping to the mitochondrial chromosome
- **Freq1A** — fraction of reads whose first base is adenine (a cap-specific signature; high values suggest good cap enrichment)
